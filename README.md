# 📊 Análise de Vendas e Lucro — Power BI

Este projeto foi desenvolvido com o objetivo de criar um dashboard interativo no **Power BI** para análise de desempenho de vendas e lucratividade de uma empresa fictícia. Os dados abrangem o período de **setembro de 2013 a dezembro de 2014**, com informações detalhadas por produto, país, trimestre e segmento de mercado.

## 📌 Objetivos do Projeto

- Visualizar os principais indicadores de desempenho (KPIs), como:
  - Total de Vendas (Sales)
  - Unidades Vendidas (Units Sold)
  - Descontos Concedidos (Discounts)
  - Receita Bruta (Gross Sales)
  - Custo dos Produtos Vendidos (COGS)
  - Lucro (Profit)
- Analisar as vendas por:
  - Mês e Trimestre
  - Produto
  - Segmento de Mercado
  - País
- Identificar produtos mais lucrativos e mais vendidos
- Usar segmentações dinâmicas de data e país
- Explorar clusters de produtos com base no lucro

## 🛠️ Ferramentas Utilizadas

- **Power BI Desktop**
- Gráficos: barras, donuts, mapas, histogramas
- Segmentações (slicers)
- Tabelas dinâmicas
- Clusters para análise de rentabilidade

## 📈 Principais Análises

- Comparação de vendas entre EUA, Canadá, França, Alemanha e México
- Desempenho de produtos como Paseo, VTT, Velo, Amarilla, entre outros
- Distribuição de lucro por segmento de cliente (Government, Small Business, etc.)
- Evolução de vendas por mês e trimestre
- Agrupamento de produtos por lucro (clusters)

## 💡 Insights Gerados

- O segmento **Government** representa uma fatia significativa do lucro.
- Concentração de vendas no segundo semestre de 2014.
- Os **clusters de lucro** revelaram perfis distintos de desempenho por produto.
